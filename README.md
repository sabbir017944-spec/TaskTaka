# TaskTaka — Demo

A mobile-friendly Bengali front-end prototype.

## Run
Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Important limitations
- Demo-only localStorage data on one device/browser.
- No real user registration, SMS OTP, backend, admin authentication, sponsor integration, or bKash payment.
- Demo task amounts are illustrative only and are not a promise of income.
- Before any real-money launch, establish lawful sponsor revenue and clear task terms, secure server-side validation and anti-fraud controls, privacy protections, and payment-provider approval. Do not exchange rewarded ad views/clicks for cash or cash-equivalent rewards where the ad network prohibits it.
